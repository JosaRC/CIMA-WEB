# CIMA-WEB

Sitio web y catálogo industrial interactivo para **CIMA Montacargas Aguascalientes**.

## Características
- Catálogo 3D con especificaciones técnicas, tarjetas interactivas (flip card) y carrete dinámico.
- Sistema de pantallas apiladas con scroll 100% natural y mesetas de estancia extendida.
- Calculadora técnica de requerimientos para naves industriales en Aguascalientes y Bajío.
- Sistema integral de consentimiento de cookies y preferencias de privacidad (LFPDPPP).
- Preparado y optimizado para despliegue en producción con Netlify.

## Instalación y Desarrollo
```bash
npm install
npm run dev
```

## Compilación de Producción
```bash
npm run build
```
